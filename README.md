# 영차영차!

힘을 모아야만 넘어가는 협동 타임어택. 중학교 과학의 물리·화학 현상(힘, 전기 회로, 연소, 기체, 상태 변화, 빛)을 몸으로 겪는 교실용 멀티 게임이다. 1~3학년 누구나 함께 할 수 있다.
팀(2~6명, 4명이 가장 재미있다)이 열 스테이지를 함께 넘고, 팀끼리 걸린 시간으로 순위를 겨룬다. 선생님 화면에서 할 스테이지를 골라 수업 시간에 맞춘다.

- 주소: https://dltkdwhdhkd-design.github.io/yeongcha/
- 설치·가입 없음. 브라우저만 있으면 된다(학생 기기는 키보드·터치 모두 된다).

## 수업에서 쓰는 법

**선생님 (교실 앞 화면)**
1. 주소를 열고 **방 만들기**. 큰 글씨로 방 코드 4자리가 뜬다.
2. 학생이 들어오면 저절로 팀이 나뉜다. 팀 수 −/＋, **고르게 다시 나누기**, **섞기**로 조정한다.
   이름표를 누른 뒤 다른 팀을 누르면 옮겨지고, 이름표를 두 번 누르면 내보낸다.
3. 할 스테이지와 난이도(**노말**/**하드**)를 고르고 **시작!** 같은 방의 모든 팀이 같은 난이도로 겨룬다.
4. 게임 중에는 실시간 순위와 팀별 화면이 나온다. 막힌 팀은 **넘기기**로 다음 스테이지로 보낼 수 있다(벌칙 1분 30초).
5. 모든 팀이 끝나면 결과 발표(시상대, 스테이지별 기록, 재미로 보는 상, 오늘 배운 힘 정리)가 나온다. **같은 방에서 한 판 더**로 다시 할 수 있다.

**학생**
1. 주소를 열고 **참가하기** → 별명과 방 코드 입력.
2. 대기실에서 내 팀을 확인하고, 선생님이 시작하면 바로 게임이 시작된다.

**혼자 연습**: 첫 화면의 **혼자 연습**. AI 친구 1~5명(기본 3명)과 한 팀이 되고(난이도도 고른다), 내가 할 일은 초록 화살표와 말풍선으로 알려 준다. 고른 스테이지부터 끝까지 이어서 하고, AI 친구 없이 혼자 하면 혼자서는 못 넘는 곳에 파란 "혼자" 디딤돌이 생긴다.

## 조작

| | 키보드 | 터치 |
|---|---|---|
| 걷기 | ← → (A D) | ◀ ▶ |
| 점프 | Space, ↑ (W, Z) | 점프 |
| 문 들어가기 | ↓ (S, E, Enter) | 문 (문 앞에서 나타남) |
| 처음부터 다시(투표) | R | ↺ 단추 |
| 소리 켜고 끄기 | M | 🔊 단추 |

- 친구 머리 위에 올라설 수 있다. 위에 누가 있으면 무거워서 점프를 못 하고 걸음도 느려진다.
- 팀원 절반 넘게 ↺를 누르면 그 스테이지를 처음부터 다시 한다.
- 모두가 나가는 문에 들어가야 스테이지 클리어.

| 4 | 딱 맞게 | 용수철저울 두 개에 정해진 인원이 딱 맞게 서야 문이 열리고, 발사대는 다 같이 눌렀다 한 번에 내려야 높이 튄다. | 탄성력 |

## 난이도

노말은 처음 하는 반에 알맞다. 하드는 같은 스테이지에 장치(기믹)가 더 붙어 더 생각하고 더 많이 맞춰야 한다.
통신이 늦어도 할 수 있도록, 하드라고 해서 '동시에' 판정 시간이나 버티는 시간을 짧게 조이지는 않는다 (노말과 같다).
판(방에서 시작을 누를 때)마다 배치가 조금씩 달라지는 것은 두 난이도 모두 같다.

| | 이름 | 하드에서 더 붙는 장치 |
|---|---|---|
| 1 | 영차! | 열쇠 선반이 한 칸 더 높아 **셋이 탑을 쌓아야** 오른다 (팀이 둘이면 "둘이" 디딤돌이 생긴다) |
| 2 | 미끌미끌 | 받침판 바로 앞에 **모래**: 얼음 위를 미끄러져 온 쇠 상자가 모래에서 멈추면 **다 같이** 밀어야 하고, 지나친 상자는 되밀면 모래 끝(받침판 위)에서 선다. 가시 구덩이 4개 |
| 3 | 하나 둘 셋! | 첫 턱의 단추가 열쇠 선반 앞 **유리문**도 연다 → 한 명은 턱 위에 남아 계속 밟고, 남은 사람들로 시소 발사를 해야 한다 (팀이 둘이면 한 번 밟으면 고정). 열쇠 선반이 좁다 |
| 4 | 딱 맞게 | **두 번 쏜다**: 먼저 한 명을 왼쪽 높은 선반으로 쏘아 단추를 밟게 해야 열쇠 앞 유리문이 열리고, 그다음 다시 모여 열쇠로 쏜다 |
| 5 | 둥둥 | 뗏목이 무게 **딱 3**일 때만 벽 밑을 지난다 (둘이면 가벼워 걸리고 넷이면 가라앉는다). **쇠 추(사람 2명 무게)**를 뗏목에 밀어 떨어뜨려 '한 명 + 쇠 추'로 남는 사람을 보낸다 |
| 6 | 찌릿찌릿 | 직렬 스위치가 최대 6개(인원만큼 모두)이고, 그 사이에 **합선 스위치**가 하나 섞여 있다 — 밟으면 전류가 전구를 건너뛰어 불이 꺼진다 |
| 7 | 불을 꺼라 | 공기 구멍 4개, 장작 상자는 모두가 밀어야 움직이고, 물 뿌리개 선반은 셋이 탑을 쌓는다 |
| 8 | 두둥실 | 열기구에 **2명까지만** 뜬다 → 여러 번 나눠 타야 하고, 버너 지기는 매번 버너에서 내려와 열기구를 내려보낸다 |
| 9 | 꽁꽁 사르르 | 가열판 사이에 **냉각판**이 섞여 있어 밟으면 얼음벽이 녹지 않는다. 넓은 물은 이쪽 냉각판 **두 개**를 함께 눌러야 언다 |
| 10 | 빛을 따라 | 헷갈리게 하는 발판이 2개, 마지막 스위치 선반은 셋이 탑을 쌓는다 |

## 통신과 새로 고침

- 자체 서버 없이 공개 MQTT 중계 서버 여러 곳(mosquitto, HiveMQ, shiftr.io, EMQX)을 동시에 쓴다. 같은 팀끼리는 될 수 있으면 기기끼리 직접 연결(WebRTC)해서 더 빠르게 주고받고, 안 되면 중계 서버로 주고받는다.
- 내용이 공개 서버를 지나므로 실명 대신 별명을 쓴다.
- 학교 와이파이가 중계 서버를 막으면 대기실에 "연결이 안 돼요"가 뜬다. 그때는 다른 통신망(핫스팟 등)에서 해 본다.
- 학생이 게임 중에 새로 고침하거나 잠깐 끊겨도 같은 자리로 저절로 돌아오고, 팀 진행은 이어진다.
- 선생님 화면을 새로 고침하면 첫 화면에 **열어 둔 방 다시 열기**가 나온다. 그동안에도 학생 게임은 멈추지 않는다.
- 게임 중에 들어온 학생은 인원이 적은 팀에 들어가 팀이 지난 마지막 깃발에서 시작한다.

## 만든 방식 (고칠 사람을 위해)

```
index.html, css/style.css
js/core.js     게임 규칙과 물리, 한 팀의 진행(기준 기기·팀원 화면 맞추기), 선생님 중계용 보기
js/levels.js   스테이지 열 개 (노말·하드, 판마다 조금씩 다른 배치)
js/render.js   그리기
js/net.js      중계 서버(MQTT over WebSocket) + 팀원 직접 연결(WebRTC)
js/audio.js    효과음 (Web Audio로 직접 만든 소리)
js/bot.js      AI 친구(봇): 대본대로 키를 누른다
js/ai.js       스테이지별 AI 대본
js/practice.js 혼자 연습: 나 + AI 친구들을 한 기기에서 함께 돌리고, 내가 할 일을 알려 준다
js/app.js      화면 흐름: 학생·혼자 연습·선생님
```

- 각 기기가 자기 캐릭터를 직접 움직이고(입력 지연 없음), 상자·시소·뗏목 같은 함께 쓰는 장치는 팀에서 한 기기("기준 기기")가 계산해 나눠 준다. 기준 기기가 사라지면 다른 기기가 2~3초 안에 이어받는다.
- 지연 표시: 학생 화면 위쪽 연결 표시에 '지연 약 OOms'(친구 모습이 내 화면에 늦게 보이는 정도 = 오가는 시간 + 부드럽게 잇는 몫)가 나오고, 선생님 화면의 팀 칸에는 그 팀에서 가장 큰 값이 나온다. 내 캐릭터는 지연 없이 바로 움직인다.
- 시험:
  - `node tests/stages.test.js [quick] [normal|hard]` : 봇 팀(1~6명)이 지연·유실이 있는 통신으로 열 스테이지를 노말·하드 모두 끝까지 깨는지
  - `node tests/practice.js` : 실제 브라우저의 혼자 연습(AI 친구 3명)으로 열 스테이지를 이어서 끝까지
  - `node tests/flows.js` : 실제 브라우저로 새로 고침, 기준 기기 이어받기, 늦게 들어오기, 넘기기, 선생님 새로 고침, 내보내기, 한 판 더, 방 닫기
  - `node tests/e2e.js [학생 수] [팀 수] [직접연결 1|0]` : 실제 브라우저 여러 개 + 내 컴퓨터에 띄운 중계 서버로 방 만들기부터 결과 발표까지
  - flows·e2e는 `npm i aedes@0.51 ws` 한 폴더를 `E2E_DEPS=그폴더/node_modules`로, Playwright를 `PLAYWRIGHT=...`로 알려 준다.
